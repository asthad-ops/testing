# TestMu GitHub App Demo

This is a demo web application used to test the TestMu AI GitHub App integration.

## Application

The application contains a simple login page with:

- Username field
- Password field
- Login button
- Remember Me checkbox

## Expected Login Behavior

- Valid credentials should allow the user to log in.
- Invalid credentials should display an error message.
- Empty username or password should display validation messages.

## Testing Goals

Test the login functionality, form validation, button behavior, and error handling.
